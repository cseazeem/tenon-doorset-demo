# Tenon | Intelligent Doorset Manufacturing – showcase

A static, single-page walkthrough of the Tenon doorset demo (screenshots of the working application). Plain HTML, about 1.2 MB of images, no build step.

Publish with GitHub Pages: upload the contents of this folder to the repository root, then **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
